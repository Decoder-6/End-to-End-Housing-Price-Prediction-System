# End-to-End Housing Price Prediction System

A Python machine-learning project that trains a Random Forest regression model on the Housing dataset and uses the trained model to predict median house values for new records.

## Overview

This project demonstrates an end-to-end machine-learning workflow:

1. Loads the housing data from `housing.csv`.
2. Creates a stratified train/test split using the `median_income` feature.
3. Preprocesses numerical features by imputing missing values with the median and scaling them.
4. Encodes the categorical `ocean_proximity` feature using one-hot encoding.
5. Trains a `RandomForestRegressor`.
6. Saves the trained model and preprocessing pipeline with Joblib.
7. Reads records from `input.csv`, predicts `median_house_value`, and writes the predictions to `output.csv`.

## Requirements

Use Python 3.10 or newer. Install the dependencies in a terminal from the project directory:

```bash
python -m pip install pandas numpy scikit-learn joblib
```

The code imports `root_mean_squared_error`, which is available in recent versions of scikit-learn. If you keep that import, use scikit-learn 1.4 or newer.

Alternatively, create a `requirements.txt` file containing:

```text
pandas
numpy
scikit-learn>=1.4
joblib
```

Then install with:

```bash
python -m pip install -r requirements.txt
```

## How to Run

Run these commands from the project directory so the relative file paths resolve correctly.

### 1. Train the model

Make sure `housing.csv` is present, then run:

```bash
python main.py
```

When `model.pkl` does not exist, the script trains the Random Forest model, saves `model.pkl` and `pipeline.pkl`, and creates `input.csv` from the held-out test split.

**Note:** The current script uses an `if/else` flow. On the first run, it trains and saves the model. Run `python main.py` a second time to load the saved model, process `input.csv`, and generate `output.csv`.

### 2. Generate predictions

After the model and pipeline have been created, ensure `input.csv` contains the input records you want to predict. Then run:

```bash
python main.py
```

The script applies the saved preprocessing pipeline, predicts house values, and writes the results to `output.csv`. The input CSV should contain the feature columns expected by the model, including the numerical housing features and `ocean_proximity`; it should not require a `median_house_value` target column.

## Input and Output

- **Training data:** `housing.csv`
- **Prediction input:** `input.csv`
- **Prediction output:** `output.csv`
- **Prediction target:** `median_house_value`

The model predicts values in the same units as the target column in the training dataset. Review the dataset documentation before interpreting those values.

## Model and Preprocessing

The current implementation uses:

- `RandomForestRegressor(random_state=42)`
- `SimpleImputer(strategy="median")` for numerical missing values
- `StandardScaler` for numerical features
- `OneHotEncoder(handle_unknown="ignore")` for `ocean_proximity`
- `ColumnTransformer` and `Pipeline` to apply preprocessing consistently

The train/test split is stratified by categories created from `median_income`, with a test size of 20% and a random state of 42.

## Large Model File

The trained `model.pkl` file is excluded from GitHub because it is larger than GitHub's regular 100 MiB file limit. This is intentional: the model can be regenerated by running the training workflow with `housing.csv` and the required dependencies installed.

Do not commit virtual environments, credentials, or local `.env` files.

## Current Limitations

- The script relies on filenames relative to the current working directory; run it from the project root.
- Training and inference are selected by whether `model.pkl` exists, so the first run trains and the next run performs inference.
- The repository currently does not report verified test-set metrics in `main.py`. Add metrics such as MAE, RMSE, and R² from a proper held-out evaluation before claiming model performance.
- `main_old.py` is an earlier experimental script and is not required for the main workflow.
